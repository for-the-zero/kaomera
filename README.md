# Kaomera

把摄像头画面投喂给视觉语言模型，让它为你画一个可爱的颜文字画像

## 功能特性

通过浏览器摄像头API获取实时视频流，将画面发送到视觉语言模型API进行分析，基于画面内容、表情和情绪生成个性化的颜文字

- **画中画模式** - 生成的颜文字可在独立的画中画窗口中显示，方便在其他应用中展示，比如OBS
- **输出历史** - 记录本次会话中生成的所有颜文字，点击复制
- **双预览模式** - 可选择实时显示摄像头画面或显示与结果对应的请求画面

## 技术架构

### 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | Vue 3 (组合式 API) |
| 状态管理 | Pinia |
| 构建工具 | Vite |
| 运行时 | Bun |
| UI 组件库 | shadcn-vue (基于 reka-ui) |
| 样式方案 | Tailwind CSS v4 |
| 开发语言 | TypeScript 5 |

### AI 请求机制

支持两种请求模式：

1. **固定间隔模式 (async)** - 按照 `reqItv` 配置的时间间隔持续发送请求
2. **等待模式 (wait)** - 上一次请求返回并等待固定时间后再发送下一次请求

请求会将历史画面作为上下文一并发送，帮助 AI 更好地理解连续动作
